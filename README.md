# PotionShop

마법약 제작과 숫자야구 추리를 결합한 게임 프로토타입입니다.

## Flutter 버전

새로운 보라색 픽셀 아트 상점 프로토타입은 [`flutter/`](flutter/)에 있습니다.

- 한국어 주문, 물약 판매 및 재고·골드 관리
- 레시피북 생산, 가마솥 개선, 하루 마감
- 로컬 자동 저장
- 상점 배경, 마녀와 손님 이미지, 승인된 화면 시안

실행 방법과 현재 구현 범위는 [`flutter/README.md`](flutter/README.md)를 확인하세요.

**검증 상태:** 제작 환경의 Dart SDK 오류로 Flutter 빌드와 테스트 실행은 아직 검증하지 못했습니다. 숫자야구 연구와 주간 경영 시스템은 Flutter 버전에 아직 포함하지 않았습니다.

## 기존 웹 프로토타입

루트의 `src/`는 기존 React/Vite 숫자야구 프로토타입입니다.

```sh
npm install
npm run dev
```
