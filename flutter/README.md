# 달빛 물약 상점 — 첫 영업일 도입부

기본 실행은 가게를 물려받는 첫날입니다. 누구인지, 무엇을 해야 하는지부터 알려주고 실제 판매와 연구를 연결합니다.

## 첫 플레이

1. 스승의 편지를 읽고 상점 문을 엽니다.
2. 로빈에게 준비된 숙면 물약 한 병을 건넵니다. 병이 줄고 35 G가 들어옵니다.
3. 미나의 주문으로 판매를 한 번 더 경험합니다.
4. 엘리가 진열대에 없는 시야 물약을 부탁합니다. 내일 다시 만나기로 약속합니다.
5. 문을 닫고 스승의 메모에서 첫 연구의 후보 재료를 배웁니다.
6. 숫자야구 규칙으로 재료의 투입 순서를 연구합니다. 실험 후 조합이 유지되고 기록으로 이전 조합을 불러올 수 있습니다.
7. 다음 날 엘리에게 발견한 물약을 직접 건넵니다. 엘리의 반응을 듣고 일반 상점 영업으로 넘어갑니다.

도입부에는 현재 행동 하나만 표시합니다. 생산, 재료 구입, 설비 개선은 도입부를 마친 뒤 열립니다. 연구는 재료를 소모하지 않으며, 일반 생산에만 재료를 씁니다.

연구의 완벽은 재료와 순서가 모두 맞는 개수, 불안정은 재료만 맞는 개수입니다. 첫 메모는 후보 세 가지를 알려주지만 정답 순서는 알려주지 않습니다. 연구실에서 칸을 선택해 재료를 교체하거나 기존 재료를 눌러 두 칸을 교환합니다. 끌어서 넣기도 지원합니다.

## 저장과 이전 버전

도입부의 대화 단계, 실제 재고와 자금, 연구 조합은 potionshop.opening.v1에 자동 저장합니다. 도입부 완료 후 일반 상점 진행은 potionshop.story.v1에서 이어집니다. 새로고침 후 판매를 중복 처리하지 않습니다.

이전 상점 저장 potionshop.v2와 독립 연구실 저장 potionshop.research.v1은 보존합니다. 이번 도입부는 이전 테스트에서 이미 발견한 레시피를 자동으로 가져오지 않습니다. 같은 브라우저와 주소에서만 저장이 복원됩니다.

개발 검증용 PotionShop(researchFirst: true)는 독립 연구실, researchFirst: false는 구형 상점 진입을 유지합니다. 일반 사용자는 기본 실행으로 도입부를 플레이합니다.

## 실행

이 폴더를 VS Code에서 열고 F5로 실행합니다. Flutter SDK와 Git이 필요합니다. 이 컴퓨터의 실행 주소는 http://127.0.0.1:8787/ 입니다. VS Code 실행을 종료하면 서버도 종료됩니다.

```sh
flutter pub get
flutter analyze
flutter test
flutter run -d chrome
flutter build web
```

## 범위

첫 영업에서 연구와 손님의 재방문까지 연결한 시제품입니다. 단일 시야 레시피와 기존 세 날의 상점 시스템을 사용합니다. 인물은 공통 임시 스프라이트를 사용하며, 재료는 임시 아이콘입니다. 최종 픽셀 아트, 효과음, 장기 성장, 가격 흥정, 주간 빚 상환은 아직 구현하지 않았습니다.

검증 결과는 VALIDATION.md에 기록합니다.
