# 달빛 물약 상점 — Flutter 상점 프로토타입

승인한 보라색 픽셀 아트 시안을 바탕으로 만든 첫 상점 화면입니다.

## 포함된 기능

- 인물과 글자가 없는 상점 배경, 투명 배경 마녀·손님 이미지
- 한국어 주문, 물약 선택 및 판매, 재고·골드 갱신
- 레시피북에서 재료비를 내고 물약 생산
- 가마솥 개선: 한 번에 1 → 2 → 3병 생산, 재료비도 비례
- 하루 세 손님 응대 후 정산과 다음 날 시작
- 기기 로컬 저장 및 복원, 손상된 저장 데이터 처리
- 넓은 화면의 좌우 구성, 작은 화면의 세로 스크롤 구성

처음 상태는 시안과 동일한 3일째 / 128 G입니다. 세 주문은 현재 같은 손님 스프라이트를 사용하는 임시 시나리오입니다.

## 실행

Flutter SDK가 설치된 환경에서 이 폴더를 열고 실행합니다.

```sh
flutter pub get
flutter analyze
flutter test
flutter run -d chrome
```

웹 실행 진입점은 포함되어 있습니다. Android 또는 Windows를 추가할 때는 프로젝트 루트에서 아래 명령으로 플랫폼 파일을 생성합니다.

```sh
flutter create --platforms=android,windows .
```

## 확인 상태

리소스 파일 존재와 PNG 투명도는 확인했습니다. 현재 제작 환경의 Dart SDK 3.13.5가 `Platform.resolvedExecutable` 관련 자체 오류로 중단되어 의존성 설치, 정적 분석, 테스트 실행, Flutter 빌드 및 실제 화면 검증은 완료하지 못했습니다. 작성된 테스트는 실행 통과를 의미하지 않습니다.

## 다음 단계

숫자야구 연구, 가격 설정·흥정, 주간 상환, 단골 이야기, 다른 손님, 재료별 창고는 아직 구현하지 않았습니다. 현재 생산은 골드로 재료비를 직접 지불하는 단순 모델입니다. 기능 확인을 위한 상점 화면이며 최종 게임 경제 밸런스는 아닙니다.

## 아트

`assets/art/shop.png`, `witch.png`, `customer.png`는 built-in image_gen으로 생성했습니다. 화면 글자와 버튼은 이미지에 포함하지 않고 Flutter 위젯으로 구성했습니다. 물약 아이콘은 Flutter CustomPainter로 작성했습니다. 이미지 제작 지시는 ART_PROMPTS.txt에 기록되어 있습니다.

이미지는 픽셀풍 시안 기반 리소스입니다. 최종 배포용의 저해상도 타일 격자와 프레임 애니메이션 정리는 후속 작업입니다.
