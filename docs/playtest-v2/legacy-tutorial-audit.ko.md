## 이식의 핵심과 명시적 차이

**그대로 재사용할 핵심:** 손님 요청과 물약 선택으로 시작, 동일한 숙면 정답과 재료, 지정 입력 3회, 결과 1/2→0/0→3/0, 각 결과 해설, 다음 행동 강조, 단계별 입력 잠금, 세 실험의 기록 비교.

**현재 Flutter에 맞춰야 하는 부분:** 첫 손님은 마을 농부 대신 로빈, 기존 첫 판매35G·재고3병 유지. Flutter에 없는 유료 연구·시도 제한·명성 벌점·팁·유지비를 새로 구현하지 않는다. React의 경제 설명을 사실과 다른 채로 보여주지도 않는다. 대응표와 테스트로 차이를 드러낸다.

| React 원형 | Flutter v2 이식안 | 이유 |
|---|---|---|
| 첫 손님 마을 농부, 숙면 선택 | 첫 로빈 주문 후 숙면 선택, 첫 판매 전에 스승 제조법 연습 | 요청→연구학습→판매 순서 보존, 현 등장인물/첫날 이야기를 다시 쓰지 않음 |
| 숙면 답을 알아내고 주문 성공 | 이미 알려진 숙면 제조법으로 규칙 학습 | Game 기본 discovered에 sleep이 있으므로 새 발명으로 속이지 않음 |
| 요정 가루·심해 소금·유니콘 뿔 | 동일 이름과 순서의 교육 샘플 | unicorn은 Flutter 재료에 없고 fairy는 희귀. 샘플은 연습 목록 전용이며 거래·창고·레시피 해금을 바꾸지 않음 |
| “재료비11G, 이번만 면제” | “연습과 연구는 재료를 쓰지 않아요. 판매할 물약을 제조할 때만 창고 재료를 사용해요.” | 현 Flutter 실제 규칙과 일치. 유료 실험 도입 아님 |

원형의 두 오답 예제를 “도움말 선택 사항”으로 바꾸거나 시야 레시피로 몰래 치환하지 않는다. 정확한 첫 학습 경로를 유지한다. 다시보기·숙련자 건너뛰기는 선택 제안이며 사용자 필수 요구가 아니다. 도입한다면 학습 완료 처리만 하고 돈·병·관계 포인트를 만들지 않는다.

## Flutter 상태와 이관 접점

- `opening_screen.dart:_beats[1]` 로빈 주문과 첫 `game.sell('sleep')` 사이에 학습 진입을 삽입하는 안이다. 현 stage 숫자를 일괄 밀기보다 별도 튜토리얼 상태를 붙여 구저장 stage 의미를 유지한다.
- `ResearchSession`은 현재 sight 고정, 3칸, non-rare 필터다. 그대로 호출하면 숙면학습도 시야로 채점되고 unicorn을 거부한다. `tutorialDefinition`/교육용 ingredient catalog/target recipe를 명시한 별도 세션 계약이 필요하다.
- 연습 상태·배열·기록은 실제 자유연구 `researchNotebook`과 분리한다. sleep 발견 상태와 재고는 건드리지 않는다. 완료 후 원래 첫 판매 함수만 호출한다.
- 밤 엘리의 sight 연구가 **첫 자유 연구**가 된다. 기존 메모의 답순서 누설은 학습 이후에도 일반연구 규칙과 맞지 않으므로 정답 배열을 그대로 제시하지 않는 안내로 정리하되, v1의 자발적 힌트3단계를 튜토리얼 대체재로 구현하지 않는다.
- 이미 첫 판매를 지난 구세이브는 과거 첫날로 돌리지 않는다. 미완성 sight 노트도 덮어쓰지 않는다. 튜토리얼 신규 flag는 과거 학습 여부를 사실처럼 추정하지 않고 `legacyExempt` 등으로 구분한다. 필요하면 선택 다시보기를 제공한다.

## 수용 기준

1. 안내에 따라 `[web,moon,tear]→1/2`, `[fairy,salt,tutorial_unicorn]→0/0`, `[web,tear,moon]→3/0` 순서가 동일하다.
2. 지정되지 않은 재료/슬롯 변경/설명 중 조합/중복 조합 입력을 거부한다. 다음 단계와 필요한 버튼만 읽기·키보드 접근이 가능해야 한다.
3. 모든 중간 단계에서 저장·재개해도 같은 안내·슬롯·이력을 복원한다. 연출 중 종료는 마지막 커밋된 단계로 복원하며 같은 실험을 두 번 기록하지 않는다.
4. 연습 전후 돈·재고·재료·발견·관계포인트 동일. 실제 첫 판매 후에만 -숙면1/+35G와 정상 관계사건 한 번 발생한다.
5. fairy/unicorn 샘플이 일반 상점·구매·제조·자유 연구 해금에 유출되지 않는다.
6. 이후 sight 자유연구는 무료·첫시도성공·재시도 가능, 기록 독립, 성공 물약1병 지급 보존.
7. 구세이브 stage1/2/8/9/13 및 기존 자유연구 세이브를 복원해 강제 초기화·중복지급이 없다.
