# F08·F09 버그 수정 및 검증

## 범위와 판단 근거

- 대상: `flutter/` 현재 코드. 보고서의 배포 빌드 1598880 재현 영상을 새로 확보한 것은 아니다.
- F08·F09는 현재 코드의 상태 전이와 화면 문구를 대조해 원인을 확인했다. 아래 회귀 테스트는 실제 저장 상태를 주입하고 화면을 조작한다.
- 신규 콘텐츠, 원장 스키마, 경제 규칙, 아트는 변경하지 않았다. 저장 형식과 재료·금전 계산도 유지한다.

## F08: 협회 주문 바로가기

**원인:** `ShopViewport`의 상단 협회 주문 버튼은 `menu(2)`만 호출했다. `IndexedStack` 안의 `ShopTasks`가 계속 마운트되어 `section`에 보관한 설비/영업 장부/재료 상인 페이지가 유지됐다.

**수정:** 상단 전용 `openGuildOrder()`에서 관리 화면 하위 위젯 키를 갱신하여 기본 협회 주문 페이지로 재진입하고 관리 스크롤을 맨 위로 복원한다. 일반 `상점 관리` 버튼은 기존 선택을 유지한다. 초기화 대상은 관리 화면의 일시적 UI 상태이며 `Game` 객체와 저장 데이터는 바뀌지 않는다.

**회귀 테스트:** `flutter/test/playtest_regression_test.dart`의 F08 세 사례. 설비·영업 장부·해금 후 재료 상인을 각각 방문하고, 닫기→일반 관리 재열기에서는 선택 유지, 상단 주문 바로가기에서는 조합 편지 표시를 확인한다. 바로가기 연속 클릭 및 패널 닫힌 상태에서 바로가기 재진입도 확인한다. 납품 전/완료 후 상태를 포함한다.

## F09: 완료된 연구로 안내하는 마감 버튼

**원인:** 마감 버튼 문구가 연구 상태에 관계없이 `밤 연구실로 가기`였다. 실제 밤 화면은 `researchRequested && !knows('sight')`일 때만 연구 버튼을 표시했다.

**수정:** 동일 조건을 `hasPendingResearch`로 공유한다. 미해결 요청이 있으면 기존 연구실 안내를 유지하고, 연구 완료 또는 요청 없음이면 `내일 영업 준비하기`와 생산 준비 안내를 표시한다. 밤 진입/다음 날 시작 동작은 유지한다.

**회귀 테스트:** 같은 파일의 F09 세 사례. 미해결 요청/연구 완료/요청 없음 상태에서 마감 버튼 문구, 밤 진입 후 연구 버튼 유무, 다음 날 버튼, SharedPreferences 저장된 밤 상태를 확인한다.

## 검증 결과

- `git diff --check`: 통과(작성 시점).
- 신규 위젯 회귀 테스트: 6개 작성. 기존 `shop_test.dart`는 첫날 연구 요청 후 `밤 연구실로 가기` 경로를 계속 검증한다.
- Flutter 테스트 실행 및 `flutter analyze`: **실행하지 못함**. QA 담당자가 SDK 소스를 확보했으나 Dart SDK 바이너리 다운로드가 프록시 `CONNECT 403`으로 차단되어 도구 실행이 불가능했다. 테스트 통과를 주장하지 않는다.
- 독립 QA의 테스트 소스 검토에서 납품 완료 fixture의 `sight` 발견 상태 누락을 발견했고 보완했다. `Game.decode()`의 완료 상태 유효성 조건을 대조했다. 이는 동적 실행의 대체 증거가 아니다.

예정 명령:

```sh
cd flutter
flutter test test/playtest_regression_test.dart test/shop_test.dart
flutter analyze
flutter test
```
